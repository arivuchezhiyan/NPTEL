# NPTEL Interactive Quiz Portal 🎓

An interactive, responsive web portal for practicing NPTEL assignments (Weeks 1 to 12) with instant evaluation, score breakdown, and detailed explanations.

## 🌐 Live Website
👉 **[https://arivuchezhiyan.github.io/NPTEL/](https://arivuchezhiyan.github.io/NPTEL/)**

---

## ✨ Features
- **All 12 Assignments Included**: Complete questions, formulas, diagrams, and options extracted directly from assignment materials.
- **Instant Scoring & Review**: Submit quizzes to view percentage score, correct/incorrect questions, and explanations.
- **Filter Incorrect Answers**: Dedicated tab to focus and retry only the questions you got wrong.
- **Mobile Responsive Design**: Clean, touch-friendly UI optimized for smartphones, tablets, and desktops.
- **Multiple Viewing Modes**: Full list view and Focus Card view for distraction-free practice.
